# Packet Tracer Labs

Networking labs built with Cisco Packet Tracer.

## Labs

- [VLSM + VLANs + Router-on-a-Stick](01-vlsm-vlan-lab/): split
  192.168.10.0/24 with VLSM and enable inter-VLAN routing.
- [Static Routes (3 routers)](02-static-routes-lab/) static routes between 3 routers.

- [Troubleshooting Static Routes](03-troubleshooting-static-routes-lab/): find and fix static route errors.

## What I practice

- Configuring switches and routers
- IP addressing and subnetting
- VLANs and basic troubleshooting
- VLSM
- Static routes and basic troubleshooting
